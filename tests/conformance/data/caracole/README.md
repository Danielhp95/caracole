# caracole/: the phone's runtime data

A main resource root of the Android port's `:core` (on the classpath as `caracole/<area>/…`, and in the APK).
Everything here is generated by the Python suite's `tests/test_conformance_<area>.py` and checked byte for byte
(`helpers.corpus.check`), except this file and `schema/phone.sql`, which are written by hand. Never edit a generated
file: regenerate it (`CARACOLE_CORPUS=write nix develop -c pytest -q -n 0 tests/test_conformance_*.py`). Each
file's format is its generator's docstring's, and its Kotlin reader's. The spec:
docs/superpowers/specs/2026-11-03-conformance-corpus.md.
