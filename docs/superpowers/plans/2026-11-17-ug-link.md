# A UG link pasted into the search box

Status: the owner's choices of 2026-11-17, to be built in two lanes (computer, phone) against the interfaces below.

## Why

The owner searched for 斑马斑马 and found nothing, though UG has it at `https://tabs.ultimate-guitar.com/tab/4180894`.
UG's sitemaps list that tab, and every tab of 宋冬野, by a bare `/tab/{id}`, so the index has no name for them; only an
artist page caracole read names them (ug/artist_tabs.py), and caracole reads one only for a song of the library whose
artist page it knows. A search asks no site, so nothing breaks that circle but the owner pasting an address into
overrides.toml.

Today a UG link pasted into the library page's box is read as words: `/api/search` offers `[artist_url]` with the
address as the artist's name, says YouTube's suggestion is `auto` (the page would run a yt-dlp search for the URL's
text) and would send LaCuerda's search for it.

## The owner's choices

1. A UG link is no query, as a YouTube video's link is not: its own panel takes the results' place.
2. A link caracole hasn't read is read by itself once pasted, as a pasted video is: the tab page, then the artist's
   page, at the lookup pace, once a link, within the hour's lookups. Every song of that artist is then found by a
   search, which is what breaks the circle.
3. Fetch keeps the pasted version: the lookup's `tab` pick (`caracole get --tab`), which the card's Sheet versions can
   change or clear.
4. The phone does the same in this round, ported to Kotlin and held to Python by the corpus.

## The links

`ug_urls.py` (new, the standard library alone, beside youtube_urls.py) reads a link as an address bar shows it: it holds
the one reading of UG's addresses, `ug_path` (overrides.py's `_ug_path` was), `pin_url` and `artist_page_address`,
which overrides.py imports from it (its `tab_id_from_url` reads `TAB_PATH` too), so neither reads them otherwise:

- a tab page: `/tab/{id}` or `/tab/{artist}/{song}-{type}-{id}` on a UG host, its query and fragment dropped;
- an artist page: `/artist/{slug}_{id}` or `/artist/{id}` (`?filter=chords` and the like dropped);
- anything else (UG's home, `/explore`, a search, a forum page, a link with spaces around words): no UG link. The
  spaces around a link, and those a link never holds, are `ug_urls.SPACES` (controls, U+0020, U+007F–U+00A0, and
  Unicode's spaces), never `str.strip`'s or JavaScript's `\s`, which differ; a tab's id is Python's `\d` (Unicode's
  digits, as overrides.toml reads them: JavaScript's `\p{Nd}`).

`read_link(text) -> UgLink | None`: `kind` (`"tab"` or `"artist"`), `url` (the page's address as caracole asks for it:
`pin_url` for a tab, `artist_page_address` for an artist), `tab_id` (a tab's), `type` (a slugged tab's type token, else
None). library.js's `ugLink(text)` reads the same shapes (as `youtubeVideo` mirrors youtube_urls.py), held to Python by
a test that runs both on one list of shapes (tests/helpers/ug_links.py, which web/ug_link.jsonl's `read_link` records
carry for the phone).

## `GET /api/ug/link?url=`

Read-only: the database and caracole's HTTP cache alone (`http.cached` / `CachedAnswers`), no request, no lock. JSON:

```
{
  "kind": "tab" | "artist",
  "url": "<the page's address, as above>",
  "tab_id": 4180894 | null,
  "state": "found" | "auto" | "cooling" | "spent" | "failed" | "other" | "gone",
  "why": "<in words, every state but found and auto>",
  "tab": {"artist": "Song Dongye (宋冬野)", "title": "斑马 斑马 Banma Banma Zebra Zebra",
          "type": "chords" | "tabs" | "ukulele", "version": 1 | null, "rating": 4.8 | null, "votes": 120 | null} | null,
  "artist_page": {"url": "https://www.ultimate-guitar.com/artist/634073", "read": true | false,
                  "read_at": "<stamp>" | null} | null,
  "guess": {"artist": "宋冬野", "title": "斑马斑马"},
  "song": {"id": 7, "identity": "…", "display": "宋冬野 - 斑马斑马", "has_sheet": true,
           "sheet": "<href>" | null, "this_tab": true | false} | null,
  "hits": [ <IndexHit JSON, exactly as /api/search's "index" items> ]
}
```

- `found`: caracole knows the tab's song (its `ug_index` row, its `ug_artist_tabs` row, or its page in the cache), or
  has read the artist page. `auto`: not yet, and a read may go now. `cooling` (UG's cooldown, until when), `spent`
  (the hour's lookups), `failed` (this link's read failed within the hour, kv `ug:link-failed`, or its tab page won't
  parse until it is due, kv `ug:unreadable:<tab id>`): no read now, `why` says why. `other`: a tab of a type caracole
  keeps nothing of (Guitar Pro, Power, Official, bass, drums, video: ug/page.py `KINDS`), said with no request where its
  slug names its type, else once read; or a tab page robots.txt closes. `gone`: UG answered 404 for the page (its
  cached 404; an artist's: its unfiltered page's). A tab's page is read where a pasted `[artist_url]` tab page is: as
  pasted when slugged, else at the index's slugged path for its id, else the bare `/tab/{id}` (`ug.link.page_url`).
- `tab`: what UG names the tab, from the cached page, else `ug_artist_tabs` (whose rows hold no version: `version`
  null); a slugged index row alone gives no names: its slugs, as IndexHit's `artist` and `title`, are its `guess`.
- `guess`: the names the panel fills its Artist and Title with: the hit's (below), else as a search names a song only
  an artist page lists (search.py `listed_names`: your songs' name for the artist, else `normalize.original_part` of
  UG's; the title's original part, Chinese written together, "斑马斑马"); the song's own names when there is one; an
  artist link's title "".
- `song`: the library's song that holds this tab as a version (`versions`), else the song of `guess`'s identity;
  `this_tab` whether this tab is its sheet or its pick.
- `hits`: for an artist link once read, the artist's songs (as `/api/artist` gives them, best first); for a tab, the
  hit of its song. The panel draws them with rows.js's `indexLine`, so their Fetch is the search's.

## `POST /ug/link` (`url`, `csrf`)

When `/api/ug/link`'s state is `auto`: queues `caracole ug --link=<url> --progress`, a job of no song's under
`jobs.UG_LINK` (`"ug-link:"` and the page's address), one of `jobs.INDEX_READS`; asked again while it waits or runs,
that job. Answers 202 `{"job": N, "url": "/api/jobs/N"}`. Refused (`pages.Refused`, as `read_pasted_video` refuses):
400 no UG link, 409 `found` / `other` / `gone`, 429 `cooling` / `spent` / `failed`.

Its one step, `("Reading the page on Ultimate Guitar", ("ug", "--link=<url>", "--progress"))`, reports two stages,
`("tab", "Tab page")` and `("artist", "Artist page")` (`jobs.UG_LINK_STAGES`; an artist link's job has the second
alone, `jobs._ug_link_stages`), so the panel asks `/api/ug/link` again
once the tab's names are known, before the artist page is read, as the video panel does once its `video` stage is
done. Its display: "A tab on Ultimate Guitar" (an artist link: "An artist on Ultimate Guitar"); its line's words are
status.py's and outcome.py's, from its last line.

## `caracole ug --link URL [--progress]`

commands/ug.py (a new module: A4), its logic in ug/link.py. An interactive lookup, the sixth kind (AGENTS.md's
"An interactive lookup is one of", and docs/usage.md): `exclusive(..., interactive=True)`,
`make_client(cfg, conn, "ug", run_id, interactive=True)`, a lookup's budget (`lookup_requests`, 6) within the hour's
(`lookup_per_hour`), the run named as a lookup's (`_common.lookup_run_id`).

- A tab link: its page from the cache, else one request, by ug/fetch.py's rules for a page (`_read_page`'s: a cached
  copy that won't parse asked once more, `ug:unreadable:`, RobotsClosed, a 404 its page gone). The page's artist page
  learned as the fetch learns it (kv `ug:artist_url:<key>`, filed under UG's artist name's keys), then read as the
  fetch reads an artist page (ug/fetch.py's lists: chords, then tabs, `KIND_FILTERS`, 100 a page, 30 days from the
  cache) and stored (`artist_tabs.store`, `keep_only` for a list read whole). A budget spent after the tab page is no
  failure: the tab is known, its artist's page waits.
- An artist link: its lists alone.
- Its last line, the one status.py reads, as `caracole harptabs --artist`'s: `Read: ` (what it read: "Read: 斑马 斑马
  Banma Banma Zebra Zebra by Song Dongye (宋冬野), chords; their page lists 8 tabs.", an artist's "Read: UG's page of
  Song Dongye (宋冬野) lists 8 tabs."), `Not found: ` (404) or `Not read: ` (a cooldown, a block, a spent budget, an
  error, a slug of a type caracole keeps nothing of: nothing changed). A block, a budget or an error exits 0, as a
  lookup's does; a bug exits 1; a text that is no UG link exits 2. A link `known` says is `found`, `other` or `gone`
  is said with no request; `cooling` and `spent` read nothing; `failed` is read (by hand, Try again: the page alone
  doesn't send it). ug/link.py's `said` and `known_line` word it.
- Health as every lookup's (`record_block`, `record_error`, `record_ok` after `answered_any`, never after a block or
  an error of the artist's page); a failed read noted in kv `ug:link-failed` (`{page's address: {at, error}}`, the
  links that failed within the hour, so the page doesn't send them again by itself; a read after it forgets it), a
  record that gates a request (the phone's `OwnRecords` keeps it as it is at a restore).
- `--progress`: a JSON line a stage, as `caracole youtube --video --progress` writes them.

## The library page (library_assets/library.js)

- `askSources`: a UG link goes to its panel (`linkMode`), nothing searched, no LaCuerda or YouTube send, as a video
  link does.
- The panel: the link's tab or artist; "Reading the tab page…" while `auto` (and `POST /ug/link` sent once a link a
  page, then followed on `/api/jobs/N`); then UG's names, type, version and rating, Artist and Title filled from
  `guess` (each until you type), and **Fetch this version** (primary), which posts the lookup the search's rows post
  (rows.js `getIt`: `POST /lookup` with `artist`, `title` and `tab`); a song of yours with this tab: "In your logbook"
  and Open. An artist link: their songs as `hits`, each a search row. A refusal's `why` in its words.
- From a file (no server) a UG link is words, as a video link is.
- `ugLink(text)` gives `{kind, path, type}`: the page's address, its host on it, and the tab's id are the server's
  (`url`, `tab_id`: index.html names no site's address, test_library_page.py, and JavaScript has no `int()` of
  Unicode's digits). The panel asks `/api/ug/link` and posts `/ug/link` with the text pasted, and carries what it read
  as `data-ug-kind`, `data-ug-path` and `data-ug-type`, which the shapes' browser test reads; its Fetch this version
  sends the server's `url` as `tab`. `linked(text)` (a video's link or a UG page's) is what the counts under the box
  and Enter ask.

## `/api/search` given a link

A query that is a UG link or a YouTube video's link gives no `unseen` and no `hint`, and its `lacuerda_search` and
`youtube` gates are None, so no page sends LaCuerda's search or YouTube's for a link.
