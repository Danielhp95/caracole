## Ultimate Guitar sitemaps

- `robots.txt` on both hosts reads as the plan says. `/search.php` is disallowed on `www`; `/tab/download` and `/tab/print?` are disallowed on `tabs`. Tab pages and artist pages are allowed.
- The sitemap index lists 82 children, as the plan says: `sitemap1`–`sitemap40`, `sitemap_last`, `sitemap_ukulele1`–`4`, and news, wiki, forum and similar sitemaps that hold no tabs.
- **Size.** `sitemap40` holds 50,000 URLs: 24.7 MB of XML, 1.7 MB on the wire, because it is served gzip-encoded. `sitemap_last` holds 17,701 URLs (8.7 MB, 0.6 MB on the wire). A full build is therefore about 2 million URLs: roughly 1 GB of XML to parse, but only about 70 MB to download.
- **Conditional GETs work.** Sitemaps come from Cloudflare's cache (`max-age=14400`) with an `ETag` and a `Last-Modified`, so a nightly refresh can send `If-None-Match` and usually get a 304.
- **More type tokens than the plan lists.** Seen: `chords`, `tabs`, `guitar-pro`, `bass`, `ukulele`, `power`, `official`, `video`, `musescore` and `drums`. Power Tab is in the guitar-part slot's format list, so the index keeps `power` as well as `chords`, `tabs` and `guitar-pro`.
- About 12% of entries are bare `/tab/{id}` with no slugs; the index skips them, as planned. One entry had an empty artist slug (`/tab//autosmile-chords-65163`), and some slugs start or end with a hyphen (`-feast`, `fontaines-d-c-`).
- `sitemap_last` is not "newest ids only". It holds ids from 5.75M to 6.65M, unsorted, with `lastmod` from August to October 2026. `sitemap40` is sorted (6.23M–6.60M). The newest ids (above 6.60M) appear only in `sitemap_last`, so refreshing `sitemap_last` plus the highest-numbered sitemap is right.
- **How UG writes slugs.** Accents are stripped and ñ becomes "n" (`senorita`, `corazon`); apostrophes are dropped (`ill-be-yours`); dots become hyphens (`r-e-m-`); a leading "the" is kept (`the-rifles`). The matcher therefore normalizes UG slugs and source names with the same function: it drops a leading "the", "&" and the word "and" on both sides, and also compares with hyphens removed (so `acdc` matches "AC/DC").
- **Part labels** sometimes appear in the slug, as in `froggy-went-a-courtin-intro-chords-6236009`. The matcher treats a trailing `intro`, `solo`, `outro`, `riff`, `lesson`, `acoustic`, `live` or `unplugged` as a variant of the same song.

## Ultimate Guitar tab pages

Checked on `tab/85053`, the plan's own pin example: it is "De Música Ligera (Chords, ver 2)" by Soda Stereo. The page came back 200 with an honest `tabarr/0.1` User-Agent, and no challenge page.

- `div.js-store[data-content]` → `store.page.data.tab_view.versions` exists and carries `id`, `type`, `part`, `version`, `rating`, `votes`, `tab_access_type`, `version_description` and `recording.is_acoustic`.
- **The versions list leaves out the page's own tab.** That tab sits in `store.page.data.tab`, with the same fields.
- **Versions are grouped by type and part.** The Chords page listed Chords v1, v3 and v4, plus the Official version, and nothing else. The song's Tabs, its "solo" Tabs and its Guitar Pro files form separate groups (confirmed on the artist page). So ranking a song's guitar parts needs one page per type group, not one page per song. The per-song cost is about 3–6 requests instead of the plan's 2–5.
- **UG's type `Pro` means a user-submitted Guitar Pro file** (`type_name: "Guitar Pro"`, `tab_access_type: "public"`). It is not paywalled content. The paywalled kind is `Official`. Skipping "Pro tabs", as the plan's rules section says, would drop every Guitar Pro file, so tabarr skips `Official` instead, along with anything not `public`.
- A Guitar Pro page's `tab_view.meta` carries `fileExtension` (`.gp5`), `tuning`, `instruments` and `duration` in seconds. That duration is a free signal for spotting a 14-second fragment, which the plan had deferred to file introspection.
- `part` holds labels such as `intro` and `solo`, which drive the guitar-part penalty.
- Sheet text is `tab_view.wiki_tab.content`, with chords marked `[ch]…[/ch]` and aligned blocks wrapped in `[tab]…[/tab]`, as the plan expects.

## LRCLIB

- `GET /api/get?artist_name&track_name&album_name&duration` found all 10 test songs: 5 English and 5 Spanish (Soda Stereo ×2, Jarabe de Palo, Enanitos Verdes, Joaquín Sabina). Every one had synced lyrics, and unaccented queries matched accented titles.
- **A miss currently returns `503 ServerOverloaded`, not 404**, three times in a row with `Retry-After: 1`. Hits still return 200 meanwhile. So a 503 from `/api/get` can't be read as "not found".
- `GET /api/search?track_name&artist_name` returns `[]` for a miss and a list of candidates, with durations, for a hit. Tabarr calls `/api/get` first and falls back to `/api/search`. Only an empty or non-matching search result counts as "missing"; an error leaves the song pending.
- `/api/get-cached` returned 404 even for tracks that exist, so tabarr doesn't use it.
- Responses now also carry `hasWordSync` and a `lyricsfile` (YAML) field. Tabarr keeps the raw JSON.

## LaCuerda

- `robots.txt` is empty: no restrictions.
- The artist page (`/soda_stereo/`) lists every song in `ul#b_main > li`. Each entry has a link slug, a title, and an `lcd` attribute such as `RHRTTTDTB-314865972`: one type letter per version (R = Letra y Acordes, T = Tablatura, B = Bajo, D = Batería, H = Armónica), then the version numbers in ranking order. **So the best "acordes" version can be chosen from the artist page alone.** The cost is one request per artist plus one per song.
- Version pages are `/{artist}/{song}.shtml` for version 1 and `/{artist}/{song}-{n}.shtml` after that. The sheet is in `div#t_body > pre`, with chords marked `<A>Bm</A>`.
- Slugs are not always predictable ("Algún día (Someday)" → `algun_diasomeday`). Tabarr therefore builds only the artist slug, and matches song titles against the artist page's list.

## The full sitemap set (fetched after the first spike)

All 41 tab sitemaps took 39 requests, 10–20 seconds apart. They hold **2,017,701 tab URLs** (62 MB gzipped).

**About 10% of tabs are invisible to a slug index.** 210,676 URLs (10.4%) are bare `/tab/{id}`, with no artist or song in the URL:

- **Every artist with a non-ASCII name has zero slugged rows.** Checked: Joaquín Sabina, Maná, Héroes del Silencio, Café Tacvba, Björk, Mötley Crüe, Beyoncé and Sigur Rós. 宋冬野 has none either.
- **Some accented titles by ASCII-named artists are bare too.** All nine Soda Stereo "De Música Ligera" tabs are bare (85053, 85042, 1601635, 1601636, 35952, 37649, 527120, 555890, 2528571), while their "Persiana Americana" tabs are slugged.
- Bare ids span every id range, including 6M+ (15,961 of them), so this is not only old data.

**How tabarr compensates** (amendment A6 in the task plan):

1. **UG artist pages** list every tab of an artist, bare ids included, with `song_name` in the original script, plus type, part, version, rating and votes. They are paginated at 100 per page and can be filtered (`?filter=chords|tabs|guitar_pro|power&page=N`). robots.txt allows them.
2. **An artist page URL needs the numeric id**: `/artist/joaquin_sabina` returns 404, while `/artist/soda_stereo_2946` works. Tabarr learns the URL from the `artist_url` field of any tab page it fetches for that artist, or from an `[artist_url]` override you paste once per artist.
3. **LaCuerda moves into the MVP** for Spanish songs, because its artist URLs can be built from the name.
